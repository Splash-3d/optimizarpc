# Versión publicada de Reven Boost PC

Este repositorio existe para **una sola cosa**: servir `version.json` con el
número de la última versión de Reven Boost PC que está publicada en Microsoft
Store.

La aplicación lo consulta al arrancar y avisa si hay una versión más nueva que
la instalada. No hay nada que descargar ni que ejecutar aquí: la aplicación se
instala desde la Store.

El código fuente no está en este repositorio.
